# 24H-Self-driving-car

2024 National College Students Electronic Design Competition H automatic driving car

## 项目简介

本项目是专为 **2024年全国大学生电子设计竞赛（H题）** 研发的智能自动驾驶小车系统。项目致力于实现小车在特定场景下的自主行驶与环境识别功能，核心技术涵盖嵌入式系统开发、姿态解算与控制、惯性系统以及串级 PID 控制算法等。

## 项目结构

- **`doc/`**: 项目相关文档，包括系统设计方案、硬件接线说明及开发指南等。
- **`examples/`**: 完整的应用示例代码，展示自动驾驶小车的整体运行逻辑。
- **`source/`**: 自动驾驶小车的源代码。
- **`tools/`**: 辅助工具集，包含开发与调试过程中使用的各类实用脚本及工具。
- **`LICENSE`**: 项目的许可证文件，采用 **GPL-3.0** 许可证。
- **`README.md`**: 项目的说明文件。

## 核心功能

- **自动导航**：小车能够在指定的环境中自动导航。
- **环境感知**：利用板载传感器收集环境信息，并进行快速处理与状态决策。
- **路径规划**：结合场地地图信息与实时传感器反馈，执行动态路径规划算法。

## 技术栈

- **编程语言**：主要使用 C 语言编写。
- **传感器**：小车使用陀螺仪传感器等设备进行环境感知。
- **硬件平台**：嵌入式开发平台，支持开发和调试的硬件设备。


运行项目的命令和步骤会根据你的硬件平台和配置有所不同。一般来说，你需要连接小车的硬件并运行相关的控制程序。
